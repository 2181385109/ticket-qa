# 05 · 附件等价类划分

方法:**等价类划分**(主)+ **边界值分析**(大小、文件名长度)。

为什么用等价类:附件校验是三层过滤(ADR-008),每一层的输入域都能切成"通过 / 不通过"的类,
而绕过手法本质上就是"在某一层伪装成有效类"。把每层的无效类列全、再加跨层组合,
比堆一百个奇怪文件名更能说明覆盖了什么。

校验顺序(`AttachmentService.upload`):权限 → 非空 → 大小 → 扩展名白名单 → 声明 MIME 与扩展名一致 → 魔数与扩展名一致 → UUID 落盘。
顺序本身也是被测点:超大的 `.php` 报 41301 而不是 41502(`sizeCheckedBeforeExtension`);无权限时什么校验都不做(`accessCheckedFirst`)。

## 1. 扩展名层(L1)——按最后一个点取、小写、白名单 jpg/png/pdf/txt

| 类 | 代表 | 期望 | 用例 |
|---|---|---|---|
| 有效:白名单四种 | `photo.png` `photo.jpg` `doc.pdf` `note.txt` | 通过本层 | `test_valid_types` |
| 有效:大小写 | `PHOTO.PNG` | 通过(ext 归一为 png) | `test_valid_types[upper-ext]`、单测 `validPngStoredUnderUuid` |
| 无效:可执行 / 脚本 | `shell.php` `.jsp` `.exe` `.sh` `.phtml` `.PHP5` `.pHp` | 41502 | `test_extension_not_whitelisted` |
| 无效:可被浏览器执行的"图片" | `shell.html` `shell.svg` | 41502 | 同上 |
| 无效:双扩展名(最后一个点判定) | `a.jpg.php` `photo.jpg.php` `shell.php.jpg.php` `photo.PnG.exe` | 41502 | 同上、`test_double_extension_last_dot_wins` |
| 无效:近似名 | `photo.jpeg` `photo.jpe` | 41502(白名单是精确匹配) | 同上 |
| 无效:没有扩展名 / 点结尾 / 隐藏文件 | `noext` `trailingdot.` `.htaccess` | 41502(ext 为空或 `htaccess`) | 同上 |
| 无效:空字节截断 | `shell.php\x00.jpg` | 不能 201 | `test_null_byte_truncation` |

纯函数 `extensionOf` 单独有一组参数化(`photo.JPG→jpg`、`archive.tar.gz→gz`、`noext→""`、`trailing.→""`、`.hidden→hidden`)。

## 2. 声明 MIME 层(L2)——只比 type/subtype,忽略参数

| 类 | 代表 | 期望 | 用例 |
|---|---|---|---|
| 有效:与扩展名对应 | `image/png` ↔ .png | 通过 | `test_valid_types` |
| 有效:带参数 | `text/plain; charset=utf-8`、`image/png; foo=bar` | 通过 | `test_valid_types[txt]`、`test_declared_mime_with_parameter_allowed` |
| 无效:通用二进制 | `application/octet-stream` | 41503 | `test_declared_mime_mismatch`、单测 `declaredMimeMismatch` |
| 无效:另一种合法类型 | `.png` 声明 `image/jpeg` / `text/plain` | 41503 | 同上 |
| 无效:缺失 | 不带 Content-Type | 41503(客户端必须显式声明) | `[None]`、单测 `missingContentType` |
| 无效:声明合法但扩展名不合法 | `image/png` + `shell.php` | 41502(L1 先拦) | `test_mime_cannot_rescue_extension` |
| 边角:带无法识别的 charset | `image/png; charset=binary` | 41503(观察项 KI-004,拒绝是 fail-safe) | `test_declared_mime_mismatch[charset=binary]` |

`normalizeMime` 参数化:`text/plain; charset=UTF-8→text/plain`、`IMAGE/PNG→image/png`、空→空、`garbage→garbage`。

## 3. 魔数层(L3)——文件头决定真实类型

`FileTypeSniffer`:jpg `FF D8 FF`、png `89 50 4E 47 0D 0A 1A 0A`、pdf `%PDF`;txt = 无 NUL + 合法 UTF-8 + 不命中已知魔数。

| 类 | 代表 | 期望 | 用例 |
|---|---|---|---|
| 有效:三种魔数 + 文本 | 见 `FileTypeSnifferTest.jpg/png/pdf/utf8Text` | 识别正确 | 单测 |
| 无效:文本内容伪装成图片 | PHP / HTML / SVG 命名为 .jpg/.png | 41503 | `test_magic_mismatch[php-as-jpg, php-as-png, html-as-png, svg-as-png]` |
| 无效:二进制伪装成文本 / PDF | ELF 命名为 .txt/.pdf | 41503 | `[elf-as-txt, elf-as-pdf]`、单测 `binaryAsTxt` |
| 无效:两种合法类型互换 | PNG 内容命名 .jpg、JPG 内容命名 .png | 41503 | `[png-as-jpg, jpg-as-png]`、单测 `pngContentNamedJpg` |
| 无效:假 PDF(缺 `%`) | `PDF-1.7 …` | 41503 | `[fake-pdf]` |
| 无效:含 NUL、非法 UTF-8(GBK 中文) | | 识别不出 → 41503 | 单测 `nulByteIsNotText`、`invalidUtf8IsNotText` |
| 边界:魔数不完整 | 只有 `FF D8` | 不算 jpg,也不算文本 | `truncatedMagicIsNotRecognised` |
| 边界:采样切在多字节字符中间 | `abc` + 半个"字" | 去尾后仍是 txt | `sampleCutInsideMultibyteChar` |
| 有效但值得知道:PHP 源码以 .txt 上传 | | 201,存成 UUID.txt(不可执行) | `test_php_as_txt_is_stored_inert` |
| **已知局限:polyglot** | PNG 头 + PHP 尾 | 当前 201;期望 415 → xfail(KI-002) | `test_polyglot_png_php` |

## 4. 大小——边界值(闭区间上界 5MB)

| 点 | 大小 | 期望 | 用例 |
|---|---|---|---|
| 下界 | 0 字节 | 41501(空) | `test_empty_file`、单测 `emptyFileRejected` |
| 上界 | 5 × 1024 × 1024 整 | 201 | `test_size_boundary`、单测 `exactlyMaxSizeAllowed` |
| 上界 + 1 | 5MB + 1 字节 | 41301,不落盘、不落库 | 同上、单测 `oneByteOverMaxRejected` |
| 容器上限 + 1 | 8MB + 1 | 413(`MaxUploadSizeExceededException`) | `test_oversize` |

## 5. 路径与文件名

规格:文件名重命名为 UUID,原始名只进数据库。攻击面是原始名参与路径拼接。

| 类 | 代表 | 期望 | 用例 |
|---|---|---|---|
| 相对穿越 | `../../../etc/passwd.png`、`....//....//evil.png`、`photo.png/../../evil.png` | 201,storedName 为 UUID,无 `/ \ ..`,目录外无文件 | `test_path_traversal_neutralised`、单测 `pathTraversalNeutralised` |
| 绝对 / Windows 路径 | `/etc/cron.d/evil.png`、`C:\Windows\evil.png`、`..\..\win.ini.png` | 同上 | 同上、单测 `windowsPathTraversalNeutralised` |
| URL 编码的穿越 | `%2e%2e%2f%2e%2e%2fevil.png` | 同上 | 同上 |
| 超长文件名 | 300 字符 | 201,original_name 截断到 255 | `test_overlong_filename` |
| 两个 file 字段 | | 只处理第一个,附件 ≤ 1 | `test_duplicate_parts` |
